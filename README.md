# 🧮 Python Calculator

> A clean, beginner-friendly, and feature-rich **command-line calculator** built with Python. It supports basic arithmetic, scientific operations, and robust error handling through an intuitive interactive menu.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Power (`x^y`)
- √ Square Root
- 📐 Trigonometric Functions
  - Sin
  - Cos
  - Tan
- 📏 Degree-based angle input
- 🛡️ Handles invalid input gracefully
- 🚫 Prevents division by zero
- ⚡ Fast and lightweight
- 💻 Interactive command-line interface
- 📚 Beginner-friendly code structure

## 🚀 Getting Started

### Prerequisites

- Python 3.x

Check your Python version:

```bash
python --version
```

---

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/python-calculator.git
```

Go to the project folder:

```bash
cd python-calculator
```

---

## ▶️ Usage

Run the calculator:

```bash
python calculator.py
```

Then simply choose an operation from the menu and enter the required values.

---

## 🧠 Supported Operations

| Operation | Example |
|-----------|---------|
| Addition | `5 + 3` |
| Subtraction | `10 - 7` |

## ⚠️ Error Handling

The calculator safely handles common errors, including:

- Invalid numeric input
- Division by zero
- Square root of negative numbers
- Invalid menu selections
